This skill synthesizes workflow ideas rather than vendoring the upstream projects.

- [WordPress Cloudflare Migration Skill](https://github.com/marvinesu/wordpress-cloudflare-migration-skill): migration inventory, URL and claim contracts, narrow Worker architecture, reversible cutover, and production evidence. If the repository URL is unavailable, use the locally installed `wordpress-cloudflare-migration-orchestrator` skill when present.

- [Taste Skill](https://github.com/leonxlnx/taste-skill): distinctive marketing-page direction, anti-template checks, layout variety, coherent visual systems, and preflight discipline.
- [Emil Kowalski Skills](https://github.com/emilkowalski/skills): component detail, animation purpose, easing, duration, transform-origin, interaction feedback, and reduced-motion discipline.

Do not mechanically apply every upstream preference. Resolve disagreements according to the priority stated in `SKILL.md`. Preserve source licenses and attribution if upstream text, scripts, or assets are copied in a future revision.
